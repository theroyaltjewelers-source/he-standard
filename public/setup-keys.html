Generate your private keys

These keys are created inside this browser with its built-in cryptography. Nothing on this page is sent anywhere. Copy each value into Vercel → your project → Settings → Environment Variables, under the name shown.

Generate them once. If you generate new notification keys later, every device has to turn reminders on again.

Keep the private key and cron secret out of messages and documents. They only belong in Vercel (and the cron secret also in the Supabase scheduler step).
