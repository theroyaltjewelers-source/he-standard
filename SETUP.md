# Setting up The Standard

The app is live at **https://he-standard.vercel.app** (Vercel project `he-standard`, Supabase project `the-standard`).
Most configuration is automatic. This file covers what is already done, the two things only the owner can do, and how to rebuild from scratch.

## What is automatic

| Piece | How it works |
|---|---|
| Supabase URL and keys | Synced into Vercel by the Supabase ↔ Vercel integration. |
| Push notification (VAPID) keys | Generated by the server on first use and stored in the `app_config` table (service role only). |
| Scheduler secret | Generated the same way; the pg_cron jobs read it from `app_config`. |
| App URL / push contact | Default to the Vercel production address. Override with `NEXT_PUBLIC_APP_URL` / `VAPID_SUBJECT` if you add a custom domain. |
| Scheduler | `pg_cron` + `pg_net` call `/api/cron/dispatch` every minute and `/api/cron/plan` every 15 minutes (`supabase/setup/schedule_jobs.sql`). |
| Quran library | The planner imports the curated verse list verbatim from api.alquran.cloud (Uthmani text + Sahih International) in batches. |
| OAuth token encryption | AES-256-GCM, key derived from `TOKEN_ENCRYPTION_KEY` (optional) or the Supabase JWT secret. Never stored in the database. |

## Owner-only steps (secrets Claude must not handle)

### 1. Turn on the AI Coach — `ANTHROPIC_API_KEY`
1. console.anthropic.com → API keys → Create key.
2. Vercel → `he-standard` → Settings → Environment Variables → add `ANTHROPIC_API_KEY` (Production, Sensitive).
3. Optional: `ANTHROPIC_MODEL` (default `claude-sonnet-5-5`).
4. Deployments → ⋯ → Redeploy.
5. In the app: Settings → turn on **AI analysis** (consent). The Coach, AI follow-up questions, Reflect Deeper, verse reflections and weekly interpretations all stay off until both the key and your consent exist.

### 2. Connect Google Calendar — `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`
1. console.cloud.google.com → create a project (e.g. "The Standard").
2. APIs & Services → Library → enable **Google Calendar API**.
3. OAuth consent screen → External → app name "The Standard", your email → add scope `.../auth/calendar.events` → add yourself as a **test user**.
4. Credentials → Create credentials → OAuth client ID → **Web application**.
   - Authorized redirect URI: `https://he-standard.vercel.app/api/google/callback`
5. Copy the client ID and secret into Vercel as `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` (Sensitive), then redeploy.
6. In the app: Settings → Google Calendar → Connect.

## iPhone

Open the site in Safari → Share → **Add to Home Screen**, open it from the Home Screen, then Today → **Turn on reminders**. iOS shows web-push notifications but not their action buttons; tapping a notification opens the right screen. Native push with action buttons would need an Apple Developer account and a native wrapper.

## Troubleshooting

| Symptom | Fix |
|---|---|
| Coach says AI isn't configured | Add `ANTHROPIC_API_KEY` and redeploy; turn on AI analysis in Settings. |
| Google says `redirect_uri_mismatch` | The redirect URI in Google Cloud must be exactly `https://he-standard.vercel.app/api/google/callback`. |
| Google says the app isn't verified | Expected for a personal app in testing mode: make sure your Google account is listed as a test user, then choose Continue. |
| No notifications on iPhone | Must be opened from the Home Screen icon, and notifications allowed for it in iOS Settings. |
| Prayer times missing | Faith → set your location (device or city search). |
